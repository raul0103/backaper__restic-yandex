# Backaper Panel v2

Полный бэкап **VPS** и **хостингов** на Яндекс.Диск:
1. **Файлы** — указанные папки целиком (restic)
2. **Базы** — отдельные дампы (rclone), доступы ищутся в конфигах MODX / WordPress / Laravel

Из файлового бэкапа всегда исключаются: `core/cache/**`, `**/node_modules/**`, `**/.git/**`, `**/vendor/**`.

Старая панель (`panel/`) не трогается — это отдельная версия.

## Как пользоваться (для любого пользователя)

1. Откройте в браузере раздел **«Как пользоваться»** (`/guide`).
2. **+ Сервер** → выберите Хостинг или VPS → SSH + токен Яндекс.Диска.
3. **Установить на сервер** — одна кнопка.
4. **Что бэкапить** — пути (для хостинга обычно `~`) + «Найти базы».
5. **Запустить бэкап**.

### Три шага мастера

| Шаг | Смысл |
|-----|--------|
| 1. Подключение | SSH + Яндекс.Диск + пароль шифрования |
| 2. Установка | restic + rclone на сервере |
| 3. Базы данных | файлы бэкапятся сами; поиск и выбор БД для дампов |

## Запуск

```bash
cd panel-v2
cp .env.example .env
composer install
php artisan key:generate
# в .env: DB_CONNECTION=sqlite
touch database/database.sqlite
php artisan migrate
php artisan serve --port=8001
```

Откройте http://127.0.0.1:8001

Панель v1 может работать на порту 8000 параллельно.

## Отличие от v1

| | panel (v1) | panel-v2 |
|--|------------|----------|
| Объект бэкапа | каждый сайт (MODX-проект) | весь сервер/аккаунт |
| Базы | привязаны к проекту | отдельный список дампов |
| Мастер | 4 шага (конфиги → БД → проекты) | 3 простых шага |
| Исключения | на проект | общие: cache, node_modules, .git, vendor |

## Безопасность

Без авторизации — только локально/VPN. В SQLite лежат пароли SSH и БД.
